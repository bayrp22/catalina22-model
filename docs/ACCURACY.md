# Accuracy, provenance and measurements

## Published reference

The current model uses the scanned 1977 factory brochure's specification panel. These values are locked in `model-data/published-dimensions.json`.

| Quantity | Imperial | Meters | Meaning |
| --- | --- | --- | --- |
| Hull length | 21′6″ | 6.5532 | Excludes protruding rudder/hardware |
| Maximum hull beam | 7′8″ | 2.3368 | Shell envelope, not rail width |
| Reference waterline | 19′4″ | 5.8928 | Published guide, not a hydrostatic solution |
| Keel draft raised | 2′0″ | 0.6096 | Brochure nominal keel draft |
| Keel draft lowered | 5′0″ | 1.524 | Brochure nominal keel draft |
| Mast length | 25′0″ | 7.62 | Brochure nominal mast length |

The rudder may extend below the raised-keel depth. The prior 1′8″ raised-draft figure is not the baseline used for this 1977 reference.

The tests' sub-millimeter tolerances confirm that the code retains these nominal numbers; they do not establish measurement accuracy for the user's actual boat.

## Reconstructed geometry

Hull plan outline and sheer are proportioned from the brochure drawings; underwater cross-sections are inferred. Cabin dimensions, window shapes, freeboard, bulkhead positions, berth sizes/heights, cockpit details, keel pivot/profile, galley dimensions/travel and fittings need verification.

The arrangement follows the original-design forward V-berth, port dinette, starboard berth and optional sliding galley, central keel trunk and aft companionway. Exact model year, pop-top version, keel type and boat alterations remain unconfirmed. Interior appearance and geometry can vary within the 1970s production period.

No fabricated electronics, battery installations or personal equipment have been inserted from the earlier proposed equipment drawing. That drawing is a planning reference in diagram units, not a measured installation model.

## Measurement record

For each proposed correction, retain:

1. Stable part ID and specific dimension/position.
2. Actual boat identification/configuration.
3. Before/after values in meters and original reading/units.
4. Datum, station, direction and measurement method.
5. Date, evidence file/reference and uncertainty/confidence.
6. Reviewer and affected neighboring parts.

Establish a repeatable real-boat datum first. Its relationship to the model's nominal waterline origin must be documented rather than assumed. A photo marker without known length does not supply scale. A hull scan must be calibrated and aligned before deriving offsets.
